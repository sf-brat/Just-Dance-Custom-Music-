# Just Dance Custom Music

**О проекте**
**Just Dance Custom Music** - это независимый фанатский проект, направленный на изучение и создание пользовательского музыкального контента для серии игр Just Dance.
Проект предлагает практичный алгоритм выбора подходящей музыки, подготовки аудиофайлов и создания синхронизированного караоке-контента с использованием пользовательских данных о тайминге.
Он предназначен для энтузиастов, которые хотят узнать, как можно подготовить пользовательский музыкальный контент и интегрировать его в существующую структуру игры.

# Основные функции
*Подбор музыки* - руководство по оценке подходящих аудиодорожек для пользовательских проектов.

*Подготовка аудио* - инструкции по подготовке и организации аудиофайлов для использования в игре.

*Создание пользовательского караоке* — создание и редактирование синхронизированных блоков с текстом песни.

*Редактирование тайминга текста* — настройка времени начала и продолжительности отдельных блоков с текстом песни.

*Пользовательское программное обеспечение для редактирования* - приложение на основе Python для работы с данными о тайминге караоке.

*Пошаговая документация* — иллюстрированное руководство, объясняющее весь процесс.
